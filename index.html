Guide d'utilisation
Comment utiliser Vinted Manager
1

Hébergement GitHub Pages

Pour accéder à cet outil depuis n'importe où :
1. Crée un compte sur github.com
2. Crée un nouveau repository public nommé vinted-manager
3. Upload ce fichier index.html
4. Va dans Settings → Pages → Source: main branch
5. Ton site sera disponible sur https://[ton-pseudo].github.io/vinted-manager

2

Clé API Anthropic (pour l'optimisation IA)

Va dans Paramètres, entre ta clé API depuis console.anthropic.com. La clé est stockée localement dans ton navigateur, jamais envoyée ailleurs.

3

Synchronisation Vinted

Clique "Synchroniser Vinted" en bas du menu. Claude in Chrome (extension) navigue sur ton profil, récupère toutes tes annonces actives et met à jour la base. Les nouvelles annonces sont optimisées automatiquement.

4

Photos — récupération automatique

Aucun dossier nécessaire. Le script de republication demande à Claude in Chrome de récupérer les photos directement depuis chaque annonce Vinted avant de la supprimer, puis de les réuploader sur la nouvelle annonce. Tout est automatique.

5

Republication — anti-blocage intégré

Sélectionne les annonces, clique "Republier sél." → "Lancer". Le script intègre des délais automatiques entre chaque annonce (30s par défaut) et des pauses toutes les 10 annonces pour éviter toute détection par Vinted. Configure ces délais dans Paramètres.

Recommandé : max 20 annonces par session, pas plus d'une session par jour.
